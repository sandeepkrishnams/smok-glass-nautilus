# Your Nautilus preview pane

Select a file once to preview it on the right.

## Try it

- Click **notes.txt** for a scrollable text preview.
- Click **video.mp4**, then press Play for a video preview with seeking and volume. This four-second test-pattern clip and tone were generated with FFmpeg; turn down the volume before unmuting.
- Hover briefly over any file for a temporary preview without changing selection.
- Click **sample.svg** for an image preview.
- Select this file for rendered Markdown.
- Use **Show Markdown source** to inspect the original text.
- Select **document.docx** or **document.pdf** for formatted pages, with Previous/Next controls.
- Select **sheet.xlsx** for a formatted spreadsheet grid and worksheet tabs.

## Everyday controls

- Drag the divider to resize the preview.
- Press **Ctrl + Shift + P** to hide or show it.
- Use the arrow keys in the file list to move between files.
- Double-click a file, or choose **Open in application**, to edit it.

```text
Single click → preview
Double click → open
```

The pane is read-only, so browsing previews does not modify your files.
